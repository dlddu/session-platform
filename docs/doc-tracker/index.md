월별 파일은 그 달의 스냅샷이다. 지난 달 파일은 고치지 않는다. 2026-09 이전 달 파일은 단일 파일(`docs/doc-tracker.md`) 시절의 변경 이력만 담고 있다.

## 집계 규칙 — AC 테스트 커버

월 파일의 「테스트 커버」·「AC 커버됨/미커버」·「미검증 AC」는 아래 규칙 하나로 센다. 문서를 읽고 판단해 더하거나 빼지 않는다.

- **AC 집합**: `docs/prd/*.md`의 AC 헤딩(`### AC-<문자><번호>`).
- **커버된 AC**: `docs/test/*.md` 시나리오의 `- **검증 AC**:` 줄에 그 AC id가 적힌 것. 한 시나리오가 여러 AC를 검증하면 그 줄에 모두 적는다.
- **커버로 세지 않는 것**: `검증 AC` 줄 밖의 언급 전부 — 머리말·인용문(`>`)의 「X가 함께 다룬다」, 다른 AC를 검증하는 시나리오의 기대 결과 본문에 나오는 참조, 범위 설명. 어느 문서가 「다룬다」고 적어도, 그 AC를 `검증 AC`로 든 시나리오가 없으면 미커버다.
- **테스트 문서 수**: `- **검증 AC**:` 줄이 하나 이상 있는 `docs/test/*.md` 파일 수. 시나리오 ↔ e2e 매핑 원장인 `docs/test/e2e.md`는 그런 줄이 없어 세지 않는다.

재는 법(레포 루트에서):

```bash
python3 - <<'PY'
import glob, re
acs = set()
for f in glob.glob("docs/prd/*.md"):
    acs |= set(re.findall(r"^#{2,4} (AC-[A-Z][0-9]+)", open(f).read(), re.M))
covered, docs = set(), set()
for f in glob.glob("docs/test/*.md"):
    for line in open(f):
        if line.startswith("- **검증 AC**:"):
            covered |= set(re.findall(r"AC-[A-Z][0-9]+", line)); docs.add(f)
print(f"AC {len(acs)} · 테스트 문서 {len(docs)} · 커버 {len(acs & covered)}/{len(acs)} · 미커버 {sorted(acs - covered)}")
PY
```
