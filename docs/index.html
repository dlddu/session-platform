mockup (화면 단위)

여정 단위로 전환되기 전의 화면 단위 산출물. 현재 Pages 는 이 폴더만 배포한다.

화면 단위 mockup 갤러리 new-session · workspace · agent-workspace · gated-workspace · restore 갤러리 열기 → mockup 인덱스
이 페이지는 손으로 갱신한다. 여정·mockup·문서가 늘거나 줄면 같은 커밋에서 이 파일도 고친다.
여정 mockup 링크가 실제 페이지 집합과 어긋나면 CI docs-journey-mockup 이 실패한다.
구조 점검은 design-doc-structure-validator 스킬로 한다.
